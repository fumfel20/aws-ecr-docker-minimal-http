AWS + ECR + Docker + Terraform

Web application running inside a Docker container on an AWS EC2 instance.

🚀 Terraform 📦 AWS ECR 🐳 Docker ☁️ AWS EC2

Architecture Flow:

  • Terraform provisions the Amazon ECR repository and EC2 instance.
  • The Docker image is built and pushed to AWS ECR.
  • The EC2 instance pulls the image from the ECR repository and runs the container.
